🛠️ How to Install Official Apps

  1. Get the Source: Clone the app repository from GitHub
  2. Build: Follow the app's build instructions (requires Ledger SDK)
  3. Get HEX: The build produces app.hex and app.map files
  4. Install: Use this tool to install on your dev device

📋 Build Commands (typical)

# Clone the app
git clone https://github.com/LedgerHQ/app-bitcoin-new
cd app-bitcoin-new

# Build for Nano S Plus
make BOLOS_SDK=$NANOSP_SDK

# Output files in bin/ directory:
# - app.hex (the binary)
# - app.map (symbol map)

⚠️ Requirements

  • Device must be in Development Mode
  • Ledger SDK installed (BOLOS SDK)
  • ARM GCC toolchain
  • Python 3 with ledgerblue (for some apps)
